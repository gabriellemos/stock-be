# Stock Controll

## Description

BE application built with [Nest](https://github.com/nestjs/nest) to manage stock portifolio locally.

## Project setup

```bash
$ docker-compose up -d
$ yarn install
```

## Compile and run the project

```bash
# development
$ yarn run start

# watch mode
$ yarn run start:dev

# production mode
$ yarn run start:prod
```

## Run tests

```bash
# unit tests
$ yarn run test

# e2e tests
$ yarn run test:e2e

# test coverage
$ yarn run test:cov
```
